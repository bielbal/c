Ações dos Botões

Use estes Custom IDs para ativar ações automáticas do bot

✅

Confirmação

confirm_qualquercoisa

Responde ao clique com mensagem de confirmação verde (ephemeral — só o usuário vê)

❌

Cancelamento

cancel_qualquercoisa

Responde ao clique com mensagem de cancelamento vermelha (ephemeral)

ℹ️

Informação

info_qualquercoisa

Responde ao clique com mensagem informativa (ephemeral)

🎭

Adicionar Cargo

role_add_ID_DO_CARGO

Adiciona o cargo ao usuário. Substitua ID_DO_CARGO pelo ID numérico do cargo Discord. Ex: role_add_123456789012345678

➖

Remover Cargo

role_remove_ID_DO_CARGO

Remove o cargo do usuário que clicou.

🔄

Toggle de Cargo (Auto-role)

role_toggle_ID_DO_CARGO

Se o usuário tem o cargo, remove. Se não tem, adiciona. Ideal para sistema de reações/auto-role.

🎫

Abrir Ticket

ticket_open

Cria um canal privado de suporte para o usuário. Verifica se já existe ticket aberto. O bot precisa ter permissão Manage Channels.

🔒

Fechar Ticket

ticket_close

Deleta o canal de ticket após 5 segundos. Use dentro do canal de ticket.

🎉

Participar de Sorteio

giveaway_join

Inscreve o usuário no sorteio e exibe o total de participantes. Cada usuário só entra uma vez.

👥

Ver Participantes do Sorteio

giveaway_list

Mostra quantos usuários participam do sorteio (ephemeral).

Como pegar o ID do Cargo

Para ações de cargo, você precisa do ID numérico

⚙️

Passo a passo

1. Ative o Modo Desenvolvedor no Discord: Configurações → Avançado → Modo Desenvolvedor
2. Vá em Configurações do Servidor → Cargos
3. Clique com botão direito no cargo → Copiar ID do Cargo
4. Use o ID no Custom ID do botão: role_toggle_COLE_O_ID_AQUI
