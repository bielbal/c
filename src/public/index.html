Ações dos Botões

Use estes prefixos no Custom ID do botão para ativar ações automáticas do bot

✅

Confirmação

confirm_qualquercoisa

Responde com mensagem de confirmação (ephemeral)

❌

Cancelamento

cancel_qualquercoisa

Responde com mensagem de cancelamento (ephemeral)

🎭

Adicionar Cargo

role_add_ID_DO_CARGO

Adiciona um cargo ao usuário que clicou

🔄

Toggle de Cargo

role_toggle_ID_DO_CARGO

Adiciona ou remove o cargo (auto-role)

🎫

Ticket

ticket_open

Cria um canal privado de suporte para o usuário

🎉

Sorteio

giveaway_join

Inscreve o usuário no sorteio e conta participantes
